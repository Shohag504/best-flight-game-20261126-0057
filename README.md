Coral Bay Air Rally — a complete, original chase-view flight game that plays offline in a desktop browser from its own static files. Fly a little red prop plane down the bay: pitch and bank with the arrow keys (or drag with the mouse), manage the throttle and fuel, thread eight glowing gold rings over the coast, then bring her home with a gentle landing on runway 27. A lit HUD shows altitude, speed, vertical speed, heading compass, attitude, throttle and fuel; rings refill fuel and landing pays a bonus.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Hand it in with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
